🛡️ iDReader API Portal

Get instant access to AI-powered ID document extraction (Aadhaar, PAN, Passport, DL, Voter ID).

🔑 Generate API Key

Enter your app or project name to issue a live API key.

⚠️ Save this key immediately! For security reasons, it won't be shown again.

🚀 Quickstart Integration

Call the API from your application using cURL or Python:

curl -X POST "http://localhost:8000/api/v1/extract-id" \
  -H "X-API-Key: YOUR_API_KEY" \
  -F "file=@/path/to/document.jpg"
